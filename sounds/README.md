# 提示音与自定义文件

此目录随运行包提供两段原创合成 PCM WAV：`start.wav` 为少豆时的开始提示，`end.wav` 为 15 秒冷却自然结束的到期提示。素材由本项目合成，不使用第三方游戏或音乐片段，按项目 MIT 许可提供。请保留默认文件；更换个人音效可在主界面“音效设置”完成，无需覆盖程序文件。

开始和结束提示可以分别开关、更换文件、试听或恢复默认，并可调整提示音量。建议使用短片段，避免长声音挡住下一条提示或游戏声音。

可选择 WAV、MP3、FLAC、M4A、AAC、MP4 和 M4V。PCM WAV 和 FLAC 可提供无损音频；MP4/M4V 只播放声音，不弹视频窗口，没有音轨的文件不会产生声音。不同编码与受保护媒体仍取决于本机 Windows 播放能力，请先试听。系统范围见 [Microsoft 编码列表](https://learn.microsoft.com/en-us/windows/apps/develop/media-authoring-processing/supported-codecs)。

自定义文件只保存原位置的路径引用，不复制或上传，也不自动提取/转码音轨。移动、重命名或删除原文件后，请重新选择。设置存在 `%LOCALAPPDATA%\BeanStudio\sound-settings.xml`，升级前无需把个人媒体放进程序包。

声音按本工具的确认少豆和现实时间冷却到期提示，不保证代表游戏中实际恢复事件；增长和未确认画面不发开始提示，手动清除会取消该轮结束提示。
