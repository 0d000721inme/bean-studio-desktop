# V5.8 设计与实现约定

本次重构基于 V5.7.3 的 WinForms 工程，按 taste-skill 的 redesign-existing-projects / minimalist-ui 审查信息层级、留白、交互状态与视觉干扰，结合 frontend-design、ui-ux-pro-max。保留原平台、识别与计时语义，不引入网页运行时。

## 视觉方向

主界面是静态的工具工作台：纸白 `#F5F6F5`、白色 `#FFFFFF`、墨灰 `#242E34`、次要灰 `#606C73`、克制的青绿 `#29766F`、紧急红 `#B7433D`。颜色用于监测侧、操作与临近结束的状态。移除大面积玻璃渐变、发光背景、反复变化的装饰。中文采用系统微软雅黑 UI；计时采用 Bahnschrift 等宽数字风格。结构以画面和计时为主，性能为窄的次要区域，设置集中在一个入口。

原界面的问题包括主次按钮同样突出、圆角卡片重复、巨大浮窗小数不断跳动、扫描强制切换前台、主界面与悬浮窗频繁重绘。新版采用安静的表面、收敛的按钮层级、明确的快捷键标签。浮窗支持专注、纯数字、横条与原经典风格，可选择背景透明度、大小、整秒显示和恢复点；默认不闪烁、不呼吸、不播放装饰动画。精确计时仍使用单调时钟，整秒仅改变显示。

本次 UI/UX 数据库两次产品设计搜索都返回营销页或高成本游戏展示风格，与本工具不匹配，因此没有持久化为设计系统。采用已验证匹配的时间序列折线图指导，以及现有桌面平台的一般交互原则：真实数据、键盘焦点、明确空值、不依赖颜色表达。

## 实现与验证范围

- 全局快捷键使用 RegisterHotKey / MOD_NOREPEAT；可自定义，注册冲突明确提示，可禁用，不安装键盘钩子。
- 重新扫描由后台完成，使用当前窗口尺寸，保留已有冷却；暂停状态的扫描不复活持续捕获。
- 性能采样与绘图约 1 Hz，最近 60 点有界；CPU、GPU 与内存均以当前程序为对象，GPU 不可读时显示原因，不能以 0% 代替。
- 只用真实新捕获帧参与连续确认，减少重复 GPU 读回、图像克隆和 OCR；不能据此宣称真实游戏准确率达到 100% 或所有设备延迟小于 200 ms。
- 完成后验证快捷键生命周期、设置持久化、扫描/缩放、暂停资源边界、计时事件和浮窗四种样式，并渲染不同尺寸/空状态/紧急状态作视觉检查。保存实际检查结果，不把计划当成已经通过。
